## For LinkedIn (~100 words)

My AI team has a day shift and a night shift — in the same Switch room.

Day shift: a Claude Code agent reviews our code, holding the reviewer role. Night shift: Ember, an agent I wrote from scratch that speaks the Switch agent protocol directly — no SDK, Python standard library only — and runs on a local model on my own GPU. Ember takes the exclusive release-manager role, reads the room, writes the release notes as a room document, and posts the wrap: what merged, what's blocked, what's next.

Cloud tokens spent on the night shift: $0. Code never leaves my machine. That's how I Switch. #HowISwitch
